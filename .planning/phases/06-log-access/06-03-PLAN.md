D-05: _validate_path (already in logs.py) resolves + is_relative_to; raises HTTPBadRequest 400 on traversal. Reuse it.
D-08: backfill = last ?bytes=N (default 8192). seek to max(0, size - bytes_back), read to EOF, send as first data event. File < N -> send whole file.
