# Milestone v1.0: Web API

**Status:** ✅ SHIPPED 2026-05-22
**Phases:** 1-6
**Total Plans:** 13

## Overview

Brownfield milestone that added a REST + SSE web API to the existing async Python pipeline. Six phases delivered the capability vertically: each phase shipped a working end-to-end slice — server foundation, live event streaming, pipeline control, config/feed management, database viewer, and log access — building on the previous phase until a web UI can observe and control the entire pipeline without touching the filesystem or CLI.

## Phases

### Phase 1: API Foundation

**Goal**: `--serve` flag starts an aiohttp.web server that responds to health checks; the EventBus class exists; Pipeline accepts optional EventBus; dual-mode entry is clean
**Depends on**: Nothing (first phase)
**Requirements**: INFRA-01, INFRA-02
**Plans**: 1 plan

Plans:

- [x] 01-01: Walking Skeleton — dual-mode entry, idling aiohttp server, /api/v1/health, EventBus, Pipeline accepts optional EventBus

**Details:**
Thinnest possible end-to-end slice. Created `api/` package with EventBus (broadcast-all, snapshot iteration), server factory using AppRunner+TCPSite (non-blocking), and health endpoint with uptime/version. Pipeline accepts optional `event_bus` kwarg without breaking CLI behavior.

### Phase 3: Pipeline Control

**Goal**: A client can start, stop, and inspect a pipeline run; per-feed and per-episode control works
**Depends on**: Phase 2
**Requirements**: STAT-01, CTRL-01, CTRL-02, CTRL-03, CTRL-04, CTRL-05
**Plans**: 3 plans

Plans:

- [x] 03-01: RunState dataclass + control router skeleton + GET /api/v1/status
- [x] 03-02: Run lifecycle — Pipeline stop/run_state hooks + POST /run + /run/stop + /feeds/{slug}/run
- [x] 03-03: Episode control — skipped column + EpisodeStore skip/reset + POST /episodes/{guid}/{skip,reprocess}

**Details:**
`RunState` tracks idle/running state, active task ref, per-feed episode counts. 409 gate pattern uses asyncio's single-threaded guarantee to prevent TOCTOU. `_run_pipeline_task` wrapper guarantees `reset_to_idle` on every exit path including `CancelledError`. Episode skip/reprocess endpoints with cascade-delete and DB state reset.

**Depends on**: Phase 3
**Requirements**: STAT-02, STAT-03, FEED-01, FEED-02, FEED-03, FEED-04
**Plans**: 2 plans

Plans:

- [x] 04-01: Settings slice — AppConfig extra='forbid', config_path plumbing, GET + PATCH /api/v1/settings with atomic write
- [x] 04-02: Feeds slice — GET (DB-backed counts) + POST (duplicate guard) + PATCH (title-immutable) + DELETE /api/v1/feeds

### Phase 6: Log Access

**Goal**: All log files (general + per-episode) can be listed, downloaded, and tailed in real time
**Depends on**: Phase 5

**Plans**: 3 plans

## Milestone Summary

**Key Decisions:**

- aiohttp as API server — already a dep; native async; SSE built-in — no ASGI stack needed
- Same-process server model — shared asyncio event loop; SSE trivial without IPC
- `AppRunner`+`TCPSite` for non-blocking server lifecycle (never `web.run_app()`)
- In-process EventBus for SSE — broadcast-all model with list() snapshot for concurrency safety
- Config changes apply on next run only — atomic write via temp file + `os.replace()`
- Dedicated read-only DB connection for API — WAL mode enables concurrent reads
- `_validate_path` traversal guard — `is_relative_to()` blocks encoded-slash traversal
- SSE file tail with open handle + `finally: fh.close()` — rotation detection via st_size shrink

**Issues Resolved:**

- `asyncio.Event` must be instantiated inside `async def serve()` — module-level instantiation breaks when asyncio loop not running
- `CancelledError` must re-raise in `_run_pipeline_task` wrapper — swallowed cancel breaks asyncio task lifecycle
- `ClientConnectionResetError` on SSE tail disconnect — swallowed in handler (client already gone)

**Issues Deferred:**

- EVT-02: Last-Event-ID SSE replay buffer — v2
- EVT-03: SSE heartbeat ping — v2
- SEC-01: API key authentication — v2
- DB-05: Topics endpoint — v2
- INFRA-03: CORS middleware — v2 (when UI and API are on different origins)

**Technical Debt Incurred:**

- Pre-existing dead function `_run_all_patches` in `tests/test_pipeline.py` reduces global coverage to 99.98%; not touched (out of scope)
- No authentication — intentional for v1 local network deployment
