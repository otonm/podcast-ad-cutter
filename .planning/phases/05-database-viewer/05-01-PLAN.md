<objective>
Migrate the cost_tracking table to add a nullable guid column linking cost rows to episodes, and extend CostTrackingStore.save_cost() so the pipeline records the episode GUID with every cost entry. This is the prerequisite for DB-04's per-episode cost breakdown.

Purpose: DB-04 requires per-episode cost aggregation. The current cost_tracking schema has no episode linkage. This plan introduces the link without breaking existing rows (NULL guid for pre-migration data) and without altering the public CostTrackingStore behavior for existing callers (guid is optional with default None).

Output:
- Schema migration: cost_tracking gains nullable guid TEXT REFERENCES episodes(guid)
- CostTrackingStore.save_cost(cost, guid=None) signature
- Three pipeline.py call sites (ad detection, topic extraction, transcription) pass episode.guid
- Tests for the migration and the guid persistence behavior
</objective>
