## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → aiohttp PATCH /api/v1/settings | Untrusted JSON payload crosses into Pydantic validation and YAML write |
| HTTP client → aiohttp GET /api/v1/settings | Response composition must not leak credential values |
| Process → filesystem (config.yaml write) | Partial-write risk on crash; concurrent-writer risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | GET /api/v1/settings response | mitigate | Build `credentials` section exclusively via `getattr(creds, field)` → boolean → "set"/"not set"; never include the raw value; test asserts a known marker value never appears in the response body. |
| T-04-02 | Tampering | PATCH /api/v1/settings payload — `feeds` key | mitigate | Explicit `payload.pop("feeds", None)` before deep-merge so the settings endpoint cannot mutate the feed list (D-06); test verifies on-disk feeds unchanged. |
| T-04-03 | Tampering | PATCH /api/v1/settings payload — typo keys | mitigate | `AppConfig.model_config = ConfigDict(extra="forbid")` (D-07); ValidationError → HTTP 422 with JSON body; test verifies. |
| T-04-04 | Tampering | config.yaml write — crash mid-write | mitigate | `tempfile.NamedTemporaryFile(dir=config_path.parent)` + `os.replace()` (CLAUDE.md mandate); same-filesystem guarantees POSIX atomicity. |
| T-04-05 | Tampering | config.yaml — two concurrent PATCH writers | accept | Single-user local tool (per CONTEXT.md + RESEARCH.md Pitfall 6); `os.replace` atomicity ensures no partial-write corruption; no file-level lock added. |
| T-04-06 | Denial of Service | Very large PATCH payload | accept | aiohttp default body size limits apply; no additional throttling for local single-user deployment. |
</threat_model>
