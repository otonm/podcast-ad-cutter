<objective>
Expose GET /api/v1/events as a Server-Sent Events endpoint that subscribes to
the in-process EventBus on connect, streams each PipelineEvent as
`event: {type}\ndata: {json}\n\n` frames using aiohttp.web.StreamResponse, and
unsubscribes in a finally block on disconnect or cancellation. Register the
route via a `create_events_router(event_bus: EventBus) -> web.RouteTableDef`
factory mirroring the existing create_health_router pattern, and wire it into
create_app() in api/server.py. End-to-end vertical slice: tests prove that a
TestClient can GET /api/v1/events, receive emitted events with the correct
SSE framing, observe the documented response headers, support multiple
concurrent subscribers, and have subscribers cleaned up on disconnect.

This plan is independent of Plan 01 — it does not depend on pipeline emit
instrumentation. SSE tests emit directly to the bus to drive the route.
</objective>

<threat_model>
ASVS L1 considerations for the SSE route:

- Denial of service via unlimited connections: each /api/v1/events GET creates
  one subscriber queue with unbounded size. A malicious or buggy client could
  open many connections to exhaust memory. Accepted for Phase 2 (single-user
  local tool, no public network exposure per PROJECT.md). No connection cap
  enforced in Phase 2.
- Resource leak on disconnect: subscriber queue must be unsubscribed in a
  finally block (CLAUDE.md mandate). Plan enforces this with a dedicated test
  that disconnects and asserts the bus subscriber set is empty.
- Information disclosure: SSE payloads include guid, feed_slug, outcome, error
  message — same content already in logs; no credentials. Route is bound to
  the same local listener as the rest of the API (PROJECT.md: localhost-only
  default).
- Cache poisoning / proxy buffering: response sets Cache-Control: no-cache and
  X-Accel-Buffering: no to prevent intermediate buffering or cached replay.
- Input validation: GET request body is unused; no query parameters are read
  in Phase 2 (Last-Event-ID replay is EVT-02, deferred).
</threat_model>

<action>
Create api/routes/events.py with the following structure:
- `from __future__ import annotations` header
- module-level `logger = logging.getLogger(__name__)`
- imports: json, logging, aiohttp.web, api.event_bus.EventBus
- function signature:
  `def create_events_router(event_bus: EventBus) -> web.RouteTableDef:`
- Inside the factory:
  - `routes = web.RouteTableDef()`
  - `@routes.get("/api/v1/events")` decorated async handler named `events`
    taking `(request: web.Request) -> web.StreamResponse`
  - In the handler:
    1. Construct `resp = web.StreamResponse()` and set headers BEFORE
       `await resp.prepare(request)`:
       - resp.headers["Content-Type"] = "text/event-stream"
       - resp.headers["Cache-Control"] = "no-cache"
       - resp.headers["X-Accel-Buffering"] = "no"
    2. `await resp.prepare(request)`
    3. `queue = event_bus.subscribe()`
    4. `try:` `while True: event = await queue.get()` then build
       `data = f"event: {event.type}\ndata: {json.dumps(event.payload)}\n\n"`
       then `await resp.write(data.encode())`
    5. `finally: event_bus.unsubscribe(queue)`
    6. `return resp` (after the loop / for type completeness — code path
       only reached on cancellation)
  - return `routes`
Use f-strings for any log messages (CLAUDE.md). Do not await emit. Do not
catch asyncio.CancelledError inside the loop — let it propagate to finally.
</action>
<acceptance_criteria>
- api/routes/events.py exists
- File starts with `from __future__ import annotations`
- File contains `def create_events_router(event_bus: EventBus) -> web.RouteTableDef:`
- File contains `@routes.get("/api/v1/events")`
- Handler uses `web.StreamResponse` and calls `await resp.prepare(request)` before any write
- Handler sets all three headers: Content-Type: text/event-stream, Cache-Control: no-cache, X-Accel-Buffering: no
- Handler subscribes via `event_bus.subscribe()` and calls `event_bus.unsubscribe(queue)` inside a `finally:` block
- Handler blocks on `await queue.get()` with NO event/keepalive/state frame written before the first queue item is received (silent wait on idle bus, D-12)
