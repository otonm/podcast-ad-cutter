<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → API handlers | Untrusted query strings: ?offset, ?limit, ?feed; untrusted path params: {guid} |
| API handlers → SQLite | All queries use parameterized placeholders; never string-format user input into SQL |
| API handlers → filesystem | output_dir glob uses slugify() result, never raw user input; glob is confined to output_dir/feed_slug subdirectory |
| API surface → write paths | DB viewer is read-only; only GET handlers registered |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Tampering | `?feed` slug in DB-01/DB-04 query | mitigate | Reverse-resolve slug via slugify() match against config feeds; podcast title (DB-trusted value) is what is used as the parameterized SQL argument |
| T-05-02-02 | Tampering | `?offset` / `?limit` integer parsing | mitigate | Wrap `int()` in try/except ValueError → 400; `max(0, ...)` for offset; `min(..., 200)` for limit (D-06) |
| T-05-02-03 | Tampering | `{guid}` path param | mitigate | guid is used only as a parameterized SQL `?` value and never in any filesystem path; SQLite parameterization neutralizes injection |
| T-05-02-04 | Tampering | Pipeline DB connection sharing | mitigate | Every handler opens `async with Database(db_path)` per request — CLAUDE.md hard rule; verified by grep gate in acceptance criteria |
| T-05-02-05 | DoS | DB-01 unbounded result set | mitigate | `limit` capped at 200 server-side (D-06); cannot be overridden by client |
| T-05-02-06 | DoS | DB-01 filesystem glob on every row | accept | Glob is O(files in feed dir); existing pipeline performs the same operation per episode; acceptable for local-network deployment |
| T-05-02-07 | Information Disclosure | DB-03 `indices` internal column | mitigate | indices excluded from SELECT and from response shape (D-09); enforced by grep acceptance criterion |
| T-05-02-08 | Information Disclosure | DB-04 cost figures | accept | Local-deployment milestone; no auth in v1 (SEC-01 deferred to v2) |
| T-05-02-09 | Elevation of Privilege | Write paths on /api/v1/db/* | mitigate | Only GET handlers registered; grep gate asserts no POST/PATCH/DELETE/PUT exist in db.py |
| T-05-02-10 | Tampering | Path traversal via output_dir glob | mitigate | Glob pattern is built from slugify() output (alphanumeric+hyphens only) and constant strftime format — neither can introduce `..` or `/`; pubdate comes from DB, not the client |
| T-05-02-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed in this plan; existing aiohttp/aiosqlite/python-slugify already in pyproject.toml |
</threat_model>
