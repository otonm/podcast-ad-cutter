## Phase Goal

**As a** local-network operator of the podcast ad cutter, **I want to** query the pipeline's current run state via a REST endpoint, **so that** I can see whether a run is active and on what feed without inspecting the filesystem or CLI.

<objective>
Lay the vertical-slice foundation for Phase 3 by introducing the `RunState` shared-state object, wiring it into the aiohttp Application, and exposing `GET /api/v1/status` — the first end-to-end deliverable a client can call.

Purpose: Establish the substrate (RunState, control router factory, app integration) that the run/stop/episode-control endpoints in Plans 02 and 03 attach to. Without this skeleton in place, every subsequent endpoint would re-do the same plumbing.

Output: Two new modules (`api/run_state.py`, `api/routes/control.py`), a modified `api/server.py` and `main.py`, plus the test stubs that Plans 02 and 03 extend.
</objective>
