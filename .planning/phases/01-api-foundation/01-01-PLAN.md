## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network client → aiohttp server | Unauthenticated HTTP requests cross into the process over the bound TCP port |
| main.py CLI args → serve() | Operator-supplied `--host`/`--port` values cross into the server bind call |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information disclosure | `api/server.py:serve` binding default host `0.0.0.0` | accept | v1 is local-network deployment (locked decision: no auth in v1). `0.0.0.0` default exposes the port on all interfaces; this is the operator's firewall responsibility. Documented in `--host` argparse help text. |
| T-01-02 | Information disclosure | `api/routes/health.py` health response body | accept | Response contains only `status`, `uptime_seconds`, and application `version` — no secrets, no PII, no internal paths. Low-value target. |
| T-01-03 | Tampering | `api/routes/health.py` — `GET /api/v1/health` | mitigate | Endpoint takes zero inputs (no query params, no body, no path params). No injection surface by construction. |
| T-01-04 | Denial of service | `api/server.py` unauthenticated endpoint | accept | Single-user local tool on a trusted network; no rate limiting in v1. Revisit with SEC-01 (API key auth) in v2 if deployed beyond local network. |
| T-01-05 | Tampering | `api/event_bus.py:emit` iterating subscriber list | mitigate | `emit()` iterates `list(self._subscribers)` (a snapshot) so a concurrent `unsubscribe()` cannot corrupt iteration (RESEARCH Pitfall 3). |
</threat_model>
