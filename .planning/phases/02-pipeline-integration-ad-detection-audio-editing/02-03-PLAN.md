New Branch Shape (replaces current 4-branch tree):

```
Branch A: audio_exists (output file on disk) → reconstruct URL only, return immediately
Branch B: transcription_exists, no audio: download → probe → save meta → [ad tail]
Branch C: audio_exists (existing audio, not output), no transcription: probe → preprocess → transcribe → topic → [ad tail]
Branch D: nothing exists: download → probe → preprocess → transcribe → topic → [ad tail]
```

IMPORTANT — Branch A trigger condition change:
- CURRENT: Branch A triggers when `transcription_exists AND audio_exists`
- NEW: Branch A triggers when `audio_exists` ONLY (output file on disk) — `transcription_exists` is irrelevant

MUST be REMOVED. URL updates happen in two controlled places only:

2. Inside `if output_path is not None:` — only when AudioEditor produced output

Branch B note: After probe, Branch B calls `transcription_store.get_segments_for_guid(episode.guid)` and `topic_store.get_topic_for_guid(episode.guid)` to load t_segments and topic for the ad tail. NO AudioPreprocessor call (D-05).

_process_episode updated docstring:
```
Branches:
    A — output file exists on disk: compute URL only, return early.
    B — transcription exists, no output: download, probe, ad detection tail.
    C — cached audio exists, no transcription: probe, preprocess, transcribe, ad detection tail.
    D — nothing exists: full pipeline (download, probe, preprocess, transcribe, ad detection tail).

Ad detection tail (Branches B, C, D):
    Load or run ad detection. Call AudioEditor.edit(). If Path returned,
    update episode URL. If None returned, keep original URL unchanged.
```
